COMMANDES CAHPP — VERSION 0.8.1
================================

CORRECTIFS
----------

- retrait de la colonne redondante « Date du BC » dans l'historique ;
- suppression automatique du dossier temporaire de préparation lorsqu'une
  commande est marquée comme envoyée.

La date du bon reste utilisée dans le PDF et le nom du fichier. Le nettoyage du
dossier « envois » ne supprime ni le PDF original ni les documents liés.


INSTALLATION
------------

1. Créez une sauvegarde complète depuis l'application actuelle.

2. Fermez complètement Commandes CAHPP.

3. Décompressez cette archive et lancez « build_windows.bat ».

4. Depuis « dist\CommandesCAHPP-portable », copiez :

   - CommandesCAHPP.exe
   - le dossier _internal

   puis remplacez leurs anciennes versions dans votre dossier actuel.

5. Conservez impérativement vos dossiers :

   - data
   - documents
   - exports
   - envois
   - sauvegardes
   - assets

La base 0.8.0 est directement compatible avec la version 0.8.1.
