# Validation de Commandes CAHPP 1.3.2

- Extraire l'archive dans un dossier neuf.
- Vérifier que la version du fichier `cahpp_app/__init__.py` est `1.3.2`.
- Compiler puis lancer `CommandesCAHPP-Setup-1.3.2.exe`.
- Vérifier que l'application démarre et s'ouvre maximisée.
- Déplacer le séparateur entre les livraisons et les alertes.
- Vérifier les ascenseurs verticaux des deux tableaux.
- Vérifier que l'état de sauvegarde et les boutons inférieurs sont visibles.
