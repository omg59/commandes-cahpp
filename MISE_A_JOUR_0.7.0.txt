COMMANDES CAHPP — MISE À JOUR 0.7.0
====================================

Cette version améliore le confort d'utilisation :

- les confirmations d'enregistrement ne bloquent plus l'écran ;
- le bouton utilisé passe temporairement au vert ;
- la section active reste clairement indiquée dans la navigation latérale ;
- les erreurs, alertes et décisions importantes restent affichées en fenêtre.


INSTALLATION DE LA MISE À JOUR
------------------------------

1. Dans l'application actuelle, créez une sauvegarde complète ZIP.

2. Fermez complètement Commandes CAHPP.

3. Décompressez cette archive dans un nouveau dossier.

4. Double-cliquez sur « build_windows.bat ».
   Le résultat est créé dans :

   dist\CommandesCAHPP-portable

5. Dans votre dossier actuel de Commandes CAHPP, conservez impérativement :

   - data
   - documents
   - exports
   - envois
   - sauvegardes
   - assets

6. Depuis le nouveau dossier « dist\CommandesCAHPP-portable », copiez :

   - CommandesCAHPP.exe
   - le dossier _internal

   puis remplacez les anciennes versions de ces deux éléments dans votre
   dossier actuel.

7. Relancez CommandesCAHPP.exe.


COMPATIBILITÉ
-------------

La version 0.7.0 utilise la même base de données que la version 0.6.1. Elle ne
nécessite aucune réimportation du catalogue et conserve l'historique, les
réglages, les documents et les modèles existants.
