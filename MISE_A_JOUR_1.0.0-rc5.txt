COMMANDES CAHPP — CANDIDATE V1.0.0 RC5
======================================

Cette candidate reprend toutes les fonctions de la RC4c et ajuste la
présentation de l'historique ainsi que le positionnement des fenêtres.

MIGRATION DE LA BASE
--------------------

Le schéma reste en version 10. Aucune migration des données n'est nécessaire.

HISTORIQUE DES COMMANDES
------------------------

Tous les boutons d'action sont de nouveau présentés sur une seule ligne.

Pour éviter qu'un bouton soit tronqué :

- la fenêtre s'ouvre avec une largeur de 1 450 pixels ;
- sa largeur minimale est fixée à 1 420 pixels ;
- la hauteur minimale reste inchangée.

FENÊTRE DE CLASSEMENT DES DOCUMENTS
-----------------------------------

Après « Ajouter un document… », le choix du type de document est maintenant
centré sur la fenêtre « Documents associés » au lieu d'apparaître dans l'angle
supérieur gauche de l'écran.

La position est limitée aux dimensions de l'écran afin que toute la fenêtre
reste accessible.

INSTALLATION
------------

Lancer build_installer_windows.bat pour produire :

dist-installer\CommandesCAHPP-Setup-1.0.0-rc5.exe

L'installeur conserve la base, les documents, le logo, les PDF et les
sauvegardes. La détection d'Inno Setup installé uniquement pour l'utilisateur
est toujours prise en charge.
