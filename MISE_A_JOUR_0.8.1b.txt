COMMANDES CAHPP — VERSION 0.8.1b
=================================

CORRECTIF
---------

La fenêtre expliquant le glisser-déposer n'est plus affichée après
« Préparer le mail ».

Le message prérempli et le dossier contenant les pièces à joindre continuent
de s'ouvrir automatiquement.


INSTALLATION
------------

1. Fermez complètement Commandes CAHPP.

2. Décompressez cette archive et lancez « build_windows.bat ».

3. Depuis « dist\CommandesCAHPP-portable », copiez :

   - CommandesCAHPP.exe
   - le dossier _internal

   puis remplacez leurs anciennes versions dans votre dossier actuel.

4. Conservez vos dossiers `data`, `documents`, `exports`, `envois`,
   `sauvegardes` et `assets`.

La base 0.8.1 est directement compatible avec la version 0.8.1b.
