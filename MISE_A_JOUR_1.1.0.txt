COMMANDES CAHPP — VERSION 1.1.0
================================

Cette version ajoute le suivi après l'envoi d'une commande, les statistiques,
l'archivage et les contrôles de maintenance.

NOUVEAUTÉS
----------

- tableau des commandes en attente de livraison sur la vue d'ensemble ;
- bouton permettant de marquer une commande livrée ou de la remettre en
  attente ;
- page Statistiques par période, fournisseur et produit ;
- affichage facultatif des commandes archivées dans l'historique ;
- archivage automatique configurable des commandes livrées ;
- rappel de sauvegarde, contrôle d'intégrité et entretien SQLite périodique ;
- notification lorsqu'un installateur plus récent est disponible dans le
  sous-dossier partagé mises-a-jour.

MISE À JOUR
-----------

1. Fermer Commandes CAHPP sur le poste concerné.
2. Lancer CommandesCAHPP-Setup-1.1.0.exe.
3. Conserver le dossier d'installation proposé.
4. Vérifier que l'application affiche Version 1.1.0.

La base passe automatiquement du schéma 10 au schéma 11. Le catalogue, les
commandes, les documents, les PDF, les paramètres et le logo sont conservés.

NOTIFICATION DES PROCHAINES VERSIONS
------------------------------------

Déposer les prochains installateurs dans le sous-dossier mises-a-jour du
dossier partagé, avec un nom de la forme :

CommandesCAHPP-Setup-X.Y.Z.exe
