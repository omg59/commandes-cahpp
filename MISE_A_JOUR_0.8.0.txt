COMMANDES CAHPP — VERSION 0.8.0
================================

PRINCIPALES NOUVEAUTÉS
----------------------

- dates de création et de premier envoi dans l'historique ;
- modification des articles CAHPP avec corrections locales persistantes ;
- rétablissement possible des valeurs CAHPP d'origine ;
- modification et suppression logique des références hors catalogue ;
- suppression du code CAHPP sur le bon de commande PDF ;
- numéro de version affiché dans la barre latérale ;
- paramètres de composition e-mail plus universels ;
- aide intégrée pour les expressions des modèles d'e-mail.


INSTALLATION DE LA MISE À JOUR
------------------------------

1. Depuis l'application actuelle, créez une sauvegarde complète ZIP.

2. Fermez complètement Commandes CAHPP.

3. Décompressez cette archive dans un nouveau dossier.

4. Double-cliquez sur « build_windows.bat ».
   Le résultat est créé dans :

   dist\CommandesCAHPP-portable

5. Dans votre dossier actuel, conservez impérativement :

   - data
   - documents
   - exports
   - envois
   - sauvegardes
   - assets

6. Depuis le nouveau dossier « dist\CommandesCAHPP-portable », copiez :

   - CommandesCAHPP.exe
   - le dossier _internal

   puis remplacez les anciennes versions de ces deux éléments.

7. Relancez CommandesCAHPP.exe.


BASE DE DONNÉES
---------------

La structure 0.8 sépare les valeurs importées du catalogue CAHPP et les
corrections saisies par l'utilisateur. La mise à niveau du fichier SQLite est
automatique au premier lancement.

Le projet étant encore en développement, il reste recommandé de conserver une
sauvegarde de la base précédente pour faciliter les essais et les retours.
