Je publie cette première version candidate pour poursuivre les essais d’Horizon sous Windows et Linux.

### Depuis la bêta 5

- L’accueil donne plus de place aux dernières commandes et aux relances. Le graphique des achats se trouve dans les statistiques.
- Les bons de commande retrouvent le format `BC-AAAA-MM-DD_Fournisseur.pdf`. Un suffixe protège les fichiers existants en cas de doublon.
- La synchronisation préserve les modifications locales en cas de conflit entre postes. Une publication de catalogue interrompue peut reprendre.
- Les sauvegardes incluent les PDF, les pièces jointes et le logo référencés. Dans **Paramètres → Maintenance**, le bouton de restauration indique quel fichier ouvrir après extraction du ZIP.

**Avant la mise à jour**, faites une sauvegarde complète et mettez tous les postes du même partage en RC1 avant de reprendre les commandes. La base passe au schéma 16.

Sous Windows, choisissez l’installateur EXE ou le ZIP portable. Sous Linux x86_64, rendez l’AppImage exécutable ou utilisez l’archive portable. Les paquets proviennent du [build validé](https://github.com/omg59/commandes-cahpp/actions/runs/43404952633).
