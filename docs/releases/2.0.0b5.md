Je publie cette bêta d’Horizon pour Windows et Linux, avec les améliorations testées ces derniers jours.

### Nouveautés

- Nouvelle interface, nouveau logo et colonne **Fournisseur** dédiée dans le catalogue.
- Commandes regroupées : préparation, suivi et articles à recommander.
- Choix du nombre entier de cartons à l’ajout d’un article.
- Après création du bon de commande, accès direct à l’e-mail prérempli et aux pièces à joindre.
- Dates françaises dans l’interface ; noms des PDF et exports conservés en `AAAA-MM-JJ`.
- Import d’une base 1.6, profils mémorisés, sauvegardes et diagnostics accessibles dans les paramètres.

### Télécharger

- **Windows** : `CommandesCAHPP-Horizon-Setup-2.0.0b5.exe` pour l’installation, ou le ZIP portable à extraire entièrement.
- **Linux x86_64** : `CommandesCAHPP-Horizon-2.0.0b5-x86_64.AppImage`, à rendre exécutable. Une archive portable est également disponible.

Les paquets incluent Python. Pour passer de la 1.6 à Horizon, installer Horizon puis importer une copie de la base depuis l’écran d’accueil. Sous Windows, les mises à jour d’Horizon peuvent ensuite être proposées depuis le dossier partagé `mises-a-jour`.

Il s’agit d’une **bêta** : les essais sur le partage réseau réel et la restauration d’une sauvegarde restent à confirmer avant le passage en version stable.

Les fichiers publiés proviennent du [workflow validé](https://github.com/omg59/commandes-cahpp/actions/runs/42512779282), sans recompilation. Le tag identifie les sources correspondantes. `SHA256SUMS` permet de vérifier les téléchargements.
