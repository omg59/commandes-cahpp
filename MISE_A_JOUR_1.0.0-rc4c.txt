COMMANDES CAHPP — CANDIDATE V1.0.0 RC4C
=======================================

Ce correctif reprend la RC4b et corrige l'autocomplétion des fournisseurs ainsi
que la présentation des actions de l'historique.

MIGRATION DE LA BASE
--------------------

Le schéma reste en version 10. Aucune migration des données n'est nécessaire.

RECHERCHE D'UN FOURNISSEUR
--------------------------

La liste ouverte automatiquement pendant la saisie n'utilise plus le menu
natif de Windows, qui prenait le focus après la première lettre.

La nouvelle liste de suggestions :

- laisse le curseur dans le champ pendant toute la saisie ;
- se met à jour après chaque lettre ;
- accepte la sélection à la souris ;
- permet de naviguer avec les flèches Haut et Bas ;
- valide avec Entrée.

HISTORIQUE
----------

Les boutons sont répartis sur deux lignes pour rester entièrement visibles,
y compris avec la mise à l'échelle de Windows. Le bouton devient
« Régénérer la commande ».

« Documents / bon de livraison » devient « Documents associés ».

DOCUMENTS ASSOCIÉS
------------------

Le bouton rapide « Ajouter un bon de livraison » est supprimé. Le bouton
« Ajouter un document… » permet déjà de choisir « Bon de livraison », ainsi que
les confirmations, factures, devis et autres types.

INSTALLATION
------------

Lancer build_installer_windows.bat pour produire :

dist-installer\CommandesCAHPP-Setup-1.0.0-rc4c.exe

L'installeur conserve la base, les documents, le logo, les PDF et les
sauvegardes. La détection des installations utilisateur d'Inno Setup introduite
dans le correctif précédent est conservée.
